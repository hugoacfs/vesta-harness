# @deepseek-ai/dsh-vesta-routines

Vesta fork, host plugin (roadmap R8–R11, 2026-09-12). A routine is a standing agent with one hidden thread session: a folder under `$DSH_HOME/routines/<name>/` (`routine.yaml`, `notes.md`, `runs.jsonl`, `thread.json`, `archive/`) and one session on the `vesta-routine` preset in the routine's workspace, at its permission tier, titled after it and archived at creation so the sidebar never lists it. The brief is the pinned `vesta:routine-brief` prompt section. A run is one queued message carrying the run number, the trigger, the local time, any new information and the notes; every turn in the thread is logged as a run (schedule, at, manual, reminder, chat). After an unattended run the plugin records the outcome and the `Summary:` line, sends the `NOTIFY:` line per policy (`always`, `failure`, `never`, `agent`), runs `/compact` once the run's last request passed `compactAboveTokens`, and rotates the thread into `archive/` after `rotateAfterRuns` runs (or on Reset). Runs queue one at a time. The `vestaRoutines` host service gives the `routine_note` tool (`@deepseek-ai/dsh-vesta-routine-tools`) its notes. Routes under `/api/vesta/routines` feed the Routines page (`@deepseek-ai/dsh-client-ui-vesta-routines`). Runbook: `deploy/vesta/README.md`, section "Routines".
