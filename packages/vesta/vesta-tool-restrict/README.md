# @deepseek-ai/dsh-vesta-tool-restrict

Vesta fork, host plugin (roadmap T12 v2, 2026-09-17). For each preset listed in `presets`, every agent composed from it gets `tools.restrict({ allow })` applied from its own scope at `agent/created` (creation and resume), so it sees only the listed tools; tools registered per agent (upstream's reminders) stay visible. A preset row could not do this: upstream's mask filters what a scope inherits, never its own registrations, and validates names from the registering scope, so from the preset's scope its own tools are unnameable while the agents below inherit them. Configured in the `vesta-app` bundle patch for `vesta-batch`.
