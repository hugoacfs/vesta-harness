# @deepseek-ai/dsh-vesta-tool-restrict

Vesta fork, a preset row (roadmap T12 v2, 2026-09-17). Calls upstream's `tools.restrict({ allow })` in the preset's scope, so agents composed from that preset see only the listed tools. The mask covers every tool the agent inherits, the preset's own rows included, so the preset lists its own tool names; tools registered per agent (upstream's reminders) stay visible regardless. A name that is not registered yet is retried for a few seconds before the mask is dropped with a warning. Used by `deploy/vesta/agent-presets/vesta-batch` to keep the PTC SDK small.
