# @deepseek-ai/dsh-vesta-memory-notes

Vesta fork, host plugin (roadmap T13, 2026-09-17). Automatic capture and recall over the memory MCP (`ai-memory-mcp`, loopback 7332): eligible root sessions accumulate their turns; after `idleSeconds` of idleness with at least `everyTurns` user turns, or on close or archive, one short model call proposes at most `maxPerPass` durable notes as JSON (preferences, decisions with reasons, stable facts, corrections, dated events — never task state, implementation detail or secrets), each is checked against the store with `memory_search` (a close note is updated by appending, otherwise a new note is created, tagged as auto-captured), caps per session and per day apply, and every write is logged to `$DSH_HOME/memory-notes.log.jsonl`. Before every prompt (through the modes plugin's prompt router) the message is searched in the store and the best notes render as the `vesta:memory-recall` prompt section with their age. `/memory` shows status and recent automatic notes, `/memory now` captures, `/memory off|on` pauses the session, `/memory forget <name>` deletes a note (the store's git history keeps it). Incognito, routine, Batch and child sessions are never captured.
